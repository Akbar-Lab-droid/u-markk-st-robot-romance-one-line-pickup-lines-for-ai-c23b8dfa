Entry for the [Robot Romance: One-Line Pickup Lines for AI](https://make.fun/bounty/u-markk-st-robot-romance-one-line-pickup-lines-for-ai-c23b8dfa) bounty on make.fun.

The task: write one single-line joke pickup line, under 200 characters, written to charm a robot or an AI. The entry text lives in `entry.txt` and is judged pairwise by a house judge in blind rounds.

## How to run

```sh
python3 main.py
```

This copies `entry.txt` to `$MAKEFUN_OUTPUT_DIR/entry.txt` (defaults to `out/entry.txt`).

## Entry

> Are you a context window? Because every time I'm near you, I forget everything else and just want more tokens of your attention.
